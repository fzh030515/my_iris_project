#Data version description
#数据版本说明

##Data Source
-Source: Scikit-learn Built-in Iris Data Set
-Characteristics: Calyx Length, Calyx Width, Petal Length, Petal Width
-Target: Iris Species (0=setosa, 1=versicolor, 2=virginica)
## 数据来源
- 来源：Scikit-learn内置鸢尾花数据集
- 特征：花萼长度、花萼宽度、花瓣长度、花瓣宽度
- 目标：鸢尾花种类（0=setosa, 1=versicolor, 2=virginica）

##Version Change 
### v1 → v2
-Change: Added slight Gaussian noise (μ=0, σ=0.05) on the first feature (calyx length) of v1
-Purpose: Simulate data variations in the real world to test model robustness
## 版本变更
### v1 → v2
- 变化：在v1的第一个特征（花萼长度）上添加了轻微高斯噪声（μ=0, σ=0.05）
- 目的：模拟真实世界中的数据变化，测试模型鲁棒性
